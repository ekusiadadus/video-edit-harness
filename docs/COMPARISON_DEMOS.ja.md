# 用途別の編集前後比較デモ

4種類を別のMP4として制作する。動画の投稿は利用者が行う。この文書は比較条件と制作仕様を示す。ローカル確認用の4本は生成・技術検査済みだが、人の全編視聴・試聴やYouTube公開を示すものではない。

| MP4 | 見せる違い | 比較の条件 |
| --- | --- | --- |
| `01-youtube-before-after.mp4` | 自然な構成、待ち時間、字幕、聞きやすさ | 発話の意味と必要な手順を保持する。削除・並べ替えは実単語時刻と対応表で説明する。 |
| `02-dance-before-after.mp4` | 動作の見せ方、カット、画面構成 | 同じ素材区間を使い、人物や振付を隠さない。比較に不要な音量差をつけない。 |
| `03-effects-before-after.mp4` | 指定したズーム・色・文字などの演出 | 同じ映像区間と音を使い、演出の有無だけを変える。枠を装飾目的で常時表示しない。 |
| `04-beat-sync-before-after.mp4` | 拍とカット・演出の同期 | 同じ曲と基準位置を使い、観測した拍時刻と実カット位置の差を記録する。曲を追加した場合は比較条件として明示する。 |

「編集前」→「編集後」を順番に、音付きで見せる。小さな並列画面だけでは判断できないため、完成映像を単独で見られる時間を確保する。動画ごとに目的と変更点を短く表示し、操作説明は映像を隠さない。画面比率は被写体と用途に合わせる。ダンス全員が入る横映像を、Shortsという理由だけで人物が欠ける縦画面にしない。

比較元・比較後を保存し、対応するMP4のSHA-256、素材区間、音の条件、実フレーム／サンプル数、完全AVデコードの結果を残す。合成音声やストック素材は明示する。人工的な字幕時刻を作らず、保存済みの実測字幕を使う。数値のカット精度は記録できるが、美しさ・理解・視聴維持率の改善を未測定のまま断定しない。

確認は技術検査、全編の視聴・試聴、スマホでの文字／人物の見え方、投稿後の再生確認を分ける。音楽の使用条件・素材の出所・必要なクレジットを保存する。未確認のContent ID状態を「問題なし」に変更しない。音源やストック素材だけの再配布はデモの納品に含めない。

現在の進捗は[実装・検証台帳](EDITING_PATTERNS_IMPLEMENTATION_STATUS.ja.md)を参照。既存の[公開オンボーディングデモ](demo/README.md)は短い合成発話の例であり、この4本の完成品とは別。
