# 実際の編集作業を録画する

[English](SCREEN_RECORDING.md) | 日本語

Screen StudioでCodexの作業画面を録画しながら、ハーネスで実際のMP4・MOVを編集できます。Screen Studioは画面の収録、ハーネスは編集と成果物の生成を担当します。元動画とセッション履歴は残します。

## 準備

専用のCodexウィンドウとプロジェクトを用意します。公開デモには公開できる素材を使い、無関係な会話・ターミナル・メール・ブラウザタブ・通知を閉じます。認証情報は環境変数に設定し、`.env`、シェル履歴、認証情報を含む応答を画面に出しません。動画を編集する許可と、素材や録画を公開する許可は別です。

[README](../README.ja.md)に従ってプロジェクトと編集方針を設定し、色空間、音声トラック、プレビュー範囲を確認します。`session transcribe`を使う前に、対象素材のクラウド送信が許可されていることを確認します。文字起こしはOpenAI、次にAzureの順です。ローカルWhisperは使いません。

## 収録

1. Screen Studioで**Window**を選び、専用のCodexウィンドウを指定します。サイドバーを隠したい場合は**Area**を使います。
2. 必要がなければマイクとカメラをオフにします。再生音を収録する場合だけシステム音声を有効にし、無関係な音声を止めます。
3. 録画を開始し、Codexに`video-editing`スキル、プロジェクト、編集方針を指定します。実際の文字起こし確認、単語IDに沿った編集計画、選択、`session render`の実行と結果を収録します。架空のエージェント会話は使いません。
4. アプリを切り替える前に一度録画を止め、ブラウザのプレビューやFinal Cut Proは別のウィンドウ収録にします。元動画と編集後を音声付きで比較し、時間を指定した指摘と再編集も見せます。
5. 書き出した録画の原本を残し、別ファイルで待ち時間を短くします。カット、早送り、ナレーション、AI生成音声は明記します。映像と音声の同期、編集点の聞きやすさを確認します。
6. 全編で私的な情報が映っていないことを確認してから公開し、字幕を付けます。READMEにはMP4と、クリックできる小さなGIFまたは静止画を掲載します。

45〜90秒程度なら「依頼 → 文字起こしと計画 → 実レンダー → 編集前後の試聴 → 指摘と修正 → FCPXML生成」が見せやすい構成です。FCPでの読み込みと再生を見せる場合は実際に行います。XMLの出力だけではGUIでの動作確認にはなりません。

## この環境での録画範囲

Screen Studioはインストール済みで、録画操作の画面を確認しました。この環境のコンピューター操作ではCodexとGhosttyへのアクセスが制限されています。そのためCodexの録画対象ウィンドウの選択と録画開始・停止は手動で行う必要があります。これは自動操作の制限です。今回のREADMEデモは、実際の合成動画とハーネスの編集結果に説明カードを付けたもので、Codex画面の録画は含みません。
