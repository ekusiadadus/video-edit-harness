# Demo provenance

The 27-second walkthrough uses FFmpeg-generated test-pattern video and synthetic Japanese speech. It compares a 10.75-second source with an 8.53-second harness render. No personal source footage or private transcript is included.

The edited segment is the actual `warm_documentary` render from the synthetic acceptance session: word-anchored cuts, corrected transcript, and a -18 LUFS normalization target. The presentation captions and surrounding cards were composed for this walkthrough; they are not a screen recording of an editor or an agent.

The final cards report the session's measured cache reuse counts: subtitle revision 5/5, audio revision 4/5, color revision 3/5. These are examples from one synthetic session, not a general speed benchmark. The source remains unchanged. FCPXML, SRT, and LUT export are supported; Final Cut Pro GUI import and playback are not demonstrated.

`preview.gif` is a silent, reduced-resolution preview. Click it in the main README to watch or download the full 1280×720 H.264/AAC MP4 with sound. The demo and its separate `DEMO-SHA256SUMS` checksum are attached to the alpha release without changing its source tag or package archives.
