# 日本語・英語字幕の折り返し（開発版）

縦型MP4の字幕を、実際のフォントの幅で折り返します。日本語の基本的な行頭・行末禁則、英単語、数値と単位、指定した語句、Unicodeの書記素を途中で分けない配置を使います。元SRTの文字列・表示時刻・手動改行を保持し、表示時の改行だけを決めます。alpha.7には含まれません。

ユーザーは「日本語字幕を読みやすく。『Final Cut Pro』と『120fps』は途中で切らない」と指定できます。編集スキルが言語と保護する語句を設定します。字幕を文字起こししたり、新しい発話時刻を推測する機能ではありません。

## 操作

`text-layout` extraと、表示する文字に対応したローカルフォントが必要です。ほかのoptional機能を使う場合は、syncでそのextraも一緒に指定してください。

```json
{"version":1,"language":"ja","protected_phrases":["Final Cut Pro","120fps"]}
```

この内容をcaption-layout.jsonへ保存し、既に色補正済みのRec.709映像と確認したSRTを指定します。

```sh
uv run video-harness tiktok-export reviewed.mp4 --output output/portrait-captioned \
  --subtitles reviewed.srt --caption-layout caption-layout.json
```

英語はlanguageをenにします。保護する語句は完全一致で指定します。`--font`でローカルのフォントファイルを指定できます。1つの字幕が512 Unicodeコードポイントを超える場合は、重い折り返し処理の前に拒否します。収まらない語句や3行を超える字幕も拒否し、黙って語句を切ったり表示時間を変更しません。字幕の長さ・語句・手動改行を見直してください。指定を外した場合は従来の描画を使います。

新しい描画では、文字の送り幅に加え、縁取りと斜体等の左右のはみ出しを含む幅を確認します。result.jsonに言語・保護語句・ライブラリー版・表示した各行と時刻を残します。元のSRTも保持します。

## 納品と確認

セッションへ `session register-vertical` で登録し、完成縦動画の正確なSHAをレビューしてからMP4納品へ含めます。納品には、映像・元resultのSHAと表示行を結び付けたportrait-caption-layout.jsonを保存します。元のローカルパスと、映像に表示していない保護語句の一覧はコピーしません。納品バンドル全体の従来の証跡をすべて匿名化する機能ではありません。

この配置は幅820px・最大3行の作業用設定です。日本語組版の全要件や投稿先のUI安全領域への適合を保証しません。基本的な禁則の参考は[W3Cの日本語組版処理の要件](https://www.w3.org/TR/jlreq/)です。実機で字幕・顔・操作対象・投稿UIの重なり、読む時間、フォントの欠落文字を確認してください。

実単語のグループ化、意味に沿った字幕の区切りは[単語IDに結び付いた区切り案](CAPTION_GROUPS.ja.md)で指定できます。発話の省略判断は別のレビュー工程です。自動の折り返しや合成素材のテストは、人による視聴・試聴や完成作品の承認ではありません。YouTubeへのアップロードはユーザー自身が行います。
