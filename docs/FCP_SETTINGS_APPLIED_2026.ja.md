# Final Cut Pro 設定適用記録

適用日: 2026-10-06 / actor: codex / Final Cut Pro 12.4 / GPU: Apple M3

一台のMacで実施した設定変更の公開用要約。ハーネスをインストールしてもFCP設定が自動適用されるわけではない。

[制作設定の調査](FCP_BEST_PRACTICES_2026.ja.md)に基づき、現在のSDR素材を扱う設定をアプリのGUIから適用した。設定の再表示による確認と、制作物の品質検証は別の証拠である。

## 適用・確認できた項目

| 項目 | 最終状態 | 確認 |
|---|---|---|
| マスター出力先 | `Master - ProRes 422 HQ` を追加 | 環境設定を閉じて再表示し、名称と詳細を確認 |
| マスター形式 | ビデオとオーディオ、Apple ProRes 422 HQ、リニアPCM | 出力先の詳細を再読取 |
| マスター解像度・色空間 | ソースと同じ・自動 | 出力先の詳細を再読取。素材ごとの最終書き出し画面でも確認する |
| ビジュアル検索 | オンへ変更 | 読み込み設定を再表示して値1を確認。検索性のためであり画質改善ではない |
| 英語文字起こし | オフを維持 | 読み込み設定の値0を確認 |
| 参照波形 | オンを維持 | 編集設定の値1を確認 |
| バックグラウンドレンダリング | オフを維持 | 再生設定の値0を確認 |
| 読み込み時の最適化・プロキシ作成 | 両方オフを維持 | 読み込み設定の値0を確認。必要な素材には個別に生成する |
| 素材の取り込み | ライブラリストレージへコピー | 読み込み設定の値1を確認 |
| 自動補正 | バランスカラー・音声修復・無音チャンネル削除はオフ | 読み込み設定を確認 |
| 整理・ロール | Finderタグ・フォルダのキーワード、iXMLロール割当はオン | 読み込み設定を確認 |
| 色確認画面 | 2スコープ配置、ルミナンス波形＋RGBパレード、Rec.709 | 最終GUIのスコープ名称を読取 |

確認対象はローカルのSDR素材（個別の名前・保存パスは非公開）。情報インスペクタは1080×1920・30p・Rec.709・ステレオ48kHz、HEVC/AACを表示した。オリジナルはオンライン、最適化済み／プロキシは未作成。既存の色変換や画素、タイムラインの編集内容は変更していない。

## 確認の限界

- ビューアの品質優先と最適化／オリジナルを選択操作した。メニューのチェック状態はアクセシビリティ読取に出ないため、選択状態の独立した確認は未完了。
- 画面には小型の音声レベル表示を確認した。ラウドネス測定や聴取レビューの代用にはしない。
- マスターはまだ書き出していない。ProRes化は圧縮済み入力の失われた情報を復元しない。
- ディスプレイの校正・reference mode・True Tone／Night Shift、実メディアの別媒体バックアップ、復元試験は未確認。
- 外部拡張は調査候補のまま。購入・インストール・互換性試験は行っていない。
- ハーネスの実装候補H01–H21はアプリ設定とは別作業であり、未実装。[更新候補](FCP_HARNESS_BACKLOG_2026.ja.md)の受入条件を適用する。

詳細なGUI読取記録はローカルに保管し、素材情報を含むため配布しない。設定変更にソフトウェアテストは不要と判断し、アプリGUIで確認した。完成映像のdecode、色・音レビュー、FCP roundtrip、配信先再生の検証は実施していない。
